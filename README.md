# IPL Ticket Booking

A React (Vite) app with pages for Home, Matches, Book Ticket, and Booking History, using Supabase as the database.

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Create a Supabase project at https://supabase.com/, then in the SQL Editor run:
   ```sql
   create table public.bookings (
     id bigint generated by default as identity primary key,
     name text not null,
     tickets integer not null,
     stand text not null,
     venue text not null,
     created_at timestamp with time zone default now()
   );
   ```

3. Open `src/supabase.js` and replace `YOUR_SUPABASE_URL` and `YOUR_SUPABASE_ANON_KEY` with your project's values (Project Settings → API).

4. Run the app:
   ```
   npm run dev
   ```
   Then open the URL shown in the terminal (usually http://localhost:5173/).
